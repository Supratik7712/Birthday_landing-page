# 🎉 Birthday Wish Website

A simple and beautiful **static birthday website** created to surprise and celebrate my friend's special day. This project was built using basic web technologies and designed to make the birthday moment more memorable with visuals and heartfelt wishes.

---

## 🎂 Project Overview

This website is a small digital surprise created as a birthday gift for my friend.
It contains birthday wishes, decorative elements, and a visually appealing design to create a joyful celebration experience.

The goal of this project was to combine **creativity and web development** to make a personalized birthday greeting that can be shared online.

---

## ✨ Features

* 🎉 Attractive birthday-themed design
* 💌 Personalized birthday message
* 🎂 Decorative birthday elements and visuals
* 📱 Responsive layout (works on mobile and desktop)
* ⚡ Lightweight and fast loading static website

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and design
* **JavaScript** – Interactive elements

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run the **index.html** file in any web browser

No installation or additional setup is required.
